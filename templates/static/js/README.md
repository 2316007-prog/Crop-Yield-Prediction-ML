# Crop Yield Prediction Using Machine Learning

## Objective

To predict crop yield per hectare using agricultural,
weather, and field-related parameters.

## Input Features

- Crop Type
- Rainfall
- Temperature
- Soil Type
- Fertilizer Usage
- Cultivated Area

## Machine Learning Algorithms

- Linear Regression
- Random Forest Regressor

## Output

Predicted crop yield in kg/hectare.
